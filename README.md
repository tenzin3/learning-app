# learning-app

A simple Tibetan learning app with flashcards, quizzes, and pronunciation practice.

The website is live at https://tenzin3.github.io/learning-app/

## Open the app

Open `index.html` in your browser, or visit the live site above.

## Project structure

- `index.html` – main flashcards page
- `quiz.html` – quiz page for alphabet and number listening practice
- `practice.html` – pronunciation practice page
- `numbers/` – number assets and audio files
